# Laravel Boost Integration

## Context and Tool Usage

Laravel Boost accelerates AI-assisted development by providing essential configurations and tools that help AI understand the project and execute tasks safely.

- **Prefer Boost Tools**: Use Laravel Boost's generated configurations and MCP tools (`boost.json`, `.mcp.json`) to keep the workspace optimized for AI-assisted development.
- **Security and Bounds**: Adhere strictly to the defined schemas to ensure the AI agent operates under correct boundaries and accesses tools securely and efficiently.
- **Maintain Metadata**: Never manually modify generated Boost JSON configurations or metadata without understanding the target schemas, as doing so can break tool integration.
